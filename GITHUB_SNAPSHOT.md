# GitHub research snapshot

This repository backs up the current admission algorithm, comparison benchmark,
research documents, paper materials, public task/reference exports, and recorded
result files. It does not record human approval or change research checkpoint
credit.

Existing result files describe their original executions and dates. Uploading
them does not constitute a new test run or native application execution.

Installed environments, dependency downloads, bulky runtime/source copies,
database files, private diagnostic streams, credentials, local editor settings,
and compressed reviewer bundles remain in the original local workspace. The
captured rate-limit web page is excluded because it contains an API-key-like
string. Upstream source provenance is retained in `external/source-lock.json`;
external checkouts are not redistributed in this snapshot.

Consequently, this is a project backup with recorded research outputs, not a
complete standalone archive of every frozen native execution. Some links and
capture manifests refer to files retained only in the local workspace. Preserve
those originals and their consumed output allocations.

Research implementation is waiting for the user's review. The latest requested
schedule is two days for concrete, verified research results, followed by three
days of further validation for the research paper. That target is not an
achieved result or a change to the full research rubric.
