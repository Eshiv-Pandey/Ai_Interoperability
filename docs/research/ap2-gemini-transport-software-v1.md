## Implemented behavior

The hook requires the exact nonstreaming API-key model POST endpoint and a separately reviewed serialized-body bound. It preserves the original request and response objects, records allowlisted literal usage counts through the accounting core and retains conservative charges for missing, malformed or failed results. Unknown usage or a 429 stops subsequent attempts. Accounting publication failure creates a shared halt marker while preserving the original transport response/error. Response-read failure closes the response; a cleanup failure cannot replace the original read exception.

Provider transmissions outside that context are refused. Async SDK calls are refused; async HTTPX/aiohttp provider calls are refused before delegation, while unrelated traffic outside the guarded invocation passes through. A redirect/non-success response retains its charge and halts before another attempt. Class replacement is a lease: restoration changes only owned aliases and retains authority on interference. Refusing a duplicate native installation does not release an existing lease.
