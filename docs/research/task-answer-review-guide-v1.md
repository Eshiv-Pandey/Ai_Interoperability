# Minimum task and answer review

Current package: `benchmark/qualification-v1/proposal-2`, 11 November 2026.
The previous numerical pilot review remains recorded; this packet concerns
application task meaning and proposed answers.

Read these two files first:

1. [Human review packet](../../benchmark/qualification-v1/proposal-2/human-review-packet.md):
   all 68 concrete proposed answers and six decisions about task scope and evidence.
2. [Second-instance review](../../benchmark/qualification-v1/proposal-2/second-instance-review.md):
   all 48 second slots, comprising 25 proposed variations and 23 specific blockers.

For each answer you accept or dispute, inspect its same-ID record in
[evaluator-private.json](../../benchmark/qualification-v1/proposal-2/evaluator-private.json).
It supplies the public task reference, exact source citations, proposed
predicates, acceptable alternatives, near misses and state limits. The
[public tasks](../../benchmark/qualification-v1/proposal-2/application.json)
and [outcome table](../../benchmark/qualification-v1/proposal-2/candidate-table.md)
are linked context. Aggregate counts alone cannot validate individual answers.

Record your name/date, candidate ID, correct/needs revision/uncertain, and a
short reason. Include any valid alternative that is missing, an incorrect
near-miss decision, or a fixture/reset assumption that changes the answer.
The two Markdown files are the minimum orientation; source checks for accepted
answers remain part of substantive review.

The 68 base candidates and 25 variations are authored, exposed proposals.
The 23 blocked second slots have no invented answer. Source and structural
validation passed eight checks across 50 source files and 448 bound files,
with 19 constructed controls. These checks supply neither human review nor
independent held-out gold. Original runtime and route qualification remain
separate work.
