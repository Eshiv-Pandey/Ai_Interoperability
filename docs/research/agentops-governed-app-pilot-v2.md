# Original AgentOps governed-App socket diagnostic v2

This fresh successor repeats only the public d01/d03 reference recipes through
the pinned original App/root, policy and PII, server/executor and persistent
SDK/ADK stores. The deterministic model actor and TestClient ASGI intervention
remain disclosed. Frozen v1 source, captures and its strict 0/2 aggregate result
remain unchanged.

Every denied socket event now durably records its target or arguments, socket
family/type/protocol, and up to 24 sanitized stack frames before raising
PermissionError. Relevant Python source hashes, bounded excerpts and source
copies are retained. No locals, credentials or request headers are captured.
The deny policy authorizes no socket operation, including loopback binds.
Private-evaluator read probes remain denied and retained.

The diagnostic must determine the actual caller before any subsequent harness
fix is considered. Historical urllib3 IPv6 capability probes are a candidate,
not an attribution of the v1 event. A fresh event remains a strict no-network-
attempt failure; its detailed record must never be silently discarded or counted
as permission to issue a request. Actual task completion/pause and strict
aggregate qualification remain separate measurements.

The hosted workflow is `.github/workflows/agentops-governed-app-pilot-v2.yml`.
It uses the same source archive/UV lock, Python 3.13.1, original locked packages
and at least 2 GiB available physical RAM on GitHub-hosted Ubuntu 24.04.
Each case uses fresh exclusive data/state. Raw requests/SSE, tool/model journals,
closed databases, strict private evaluator, input/source copies and diagnostic
denials are retained even on failure. No live provider, held-out/human gold or
new admission integration is claimed.
