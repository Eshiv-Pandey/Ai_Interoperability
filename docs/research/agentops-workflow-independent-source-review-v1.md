# Independent original Workflow source review V1

11 November 2026. The current implementation and 18 constructed controls pass
this source review. The [review record](agentops-workflow-independent-source-review-v1.json)
binds all reviewed source bytes, original instruction literals, the two original
candidate identities and the exact software check outputs. No original
application, SDK, provider or actual retained task outcome was executed or
inspected by this review. Actual runtime qualification remains separate.

The route invokes the unchanged original `composition.app` with its original
`triage_workflow`, selected using `AGENT_ENTRYPOINT=workflow`. Runtime guards
require the original `START`, `plan`, `investigate`, `evidence_review`,
`recommend` topology, source instruction hashes, exact read-only tools and
absent per-node callbacks. It substitutes only the four declared deterministic
node models and appends observational hooks to the existing App. It does not
substitute the conversational root or qualify the original A2A server.

The review identified a substantive observation issue: original security policy
may return a sanitized replacement dictionary and short circuit a later App
observer's after-tool callback. The corrected analyzer uses raw official SDK
function-response events, joined to actual node and call IDs, as post-policy
terminal authority. Appended after-tool observations are optional and compared
only when present. The original policy remains first and unchanged. Controls
cover the short circuit, an absent after-hook journal with complete raw
terminals, and missing raw terminals that must remain partial.

Both h09 and h10 remain separate source-exposed development cases. Exact target
identifiers come from actual source results, request assertions remain distinct
from observations, and the resolved h10 conflict does not authorize a write or
note. Fresh copied data/state, workers and official session IDs, complete
database rows, source hashes, failures and cleanup are retained. The controller
uses the unchanged lock and captures the actual installed plugin-manager
source before task execution. An inspected AP2 ADK 1.28 dispatch file supports
the observation issue; it is explicitly not AgentOps locked-runtime evidence.

The actual retained allocation must still verify original runtime/App identity,
stage and tool correspondence, source-derived task outcomes, state invariants,
all failures and cleanup. Deterministic contextual JSON is a disclosed model
response format; source/control consistency is neither human gold nor evidence
of live model quality, independent holdout, native/A2A route support or the full
application study.
