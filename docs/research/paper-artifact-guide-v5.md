From the repository root, audit manuscript values, raw cells and links with a
fresh receipt path:

```powershell
python -I -S -B paper/audit_draft_v5.py --output paper/draft-audit-v5-reproduction-1.json
```

The audit reads raw evidence using the trusted checkout. It invokes no solver,
certificate checker, application, provider or downloaded source. It recomputes
all 1,320 cell projections and Table 1/3 totals, checks the unchanged Table 2/4/5
against their prior evidence, verifies bibliography/citation coverage and binds
the ledger's evidence files. Structural checks and byte bindings are not human
scientific approval.

Regenerate all five-method tables without executing experiments:
