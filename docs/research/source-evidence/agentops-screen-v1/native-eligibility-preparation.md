the acquisition/native step reviewable without fabricating a reference result
or choosing a C1 advantage threshold retrospectively.

1. Obtain an accessible checkout; read its applicable AGENTS.md instructions.
   Resolve exact branch/full commit, source/license/data hashes and clean/dirty
   status. Reconcile raw/blob/main differences and the Python subtree version.
   Save complete original source and dependency lock. Do not modify upstream
   handlers, data layer, card or SDK compatibility to obtain a favorable outcome.
2. Check the pinned lock's Windows/Python3.13 support and dependency availability
   in an isolated workspace environment. Charge acquisition/setup costs. Preserve
   every failed install/setup record. Read pyproject test configuration before
   selecting a focused command; do not silently bypass a required repository gate.
   No inference credentials, remote model or telemetry endpoint are needed for
   the explicitly supplied upstream deterministic model-double control.
3. Independently inspect the pinned upstream confirmation test and fixtures,
   application tool guards, data transaction and task/session conversion. Specify
   the original local goal: the selected seeded down service becomes operational,
   exactly one attributed/rationale-bearing audit record describes that approved
   mutation, the original A2A task completes, and unrelated rows remain unchanged.
   Confirm these requirements against the real seed and source; they are proposed
   validity requirements, not private gold already reviewed by a human.
4. Record the prospective once-only setup/control sequence before requests.
   First perform a fresh upstream source test with the maintained application
   factory and isolated temporary dataset. Preserve stdout/stderr, all assertions,
   failures and expected/actual source/runtime hashes. A passing TestClient test
   is an in-process integration control, not yet a real-pipe HTTP bridge trace.

   negotiated/accepted protocol and endpoint/binding, source-owned compatibility,
   model-double choice, public initial/follow-up request families, required part
   metadata and caller-visible confirmation fields. Freeze reset, lifecycle,
   original task/context, safety, horizon and gold/runtime separation. Keep
   synthetic caller continuity distinct from gateway-authenticated human identity.
6. Use a native pause/read/confirmation/completion with a genuinely changed local
   service record plus audit row, then evaluator-private verification. Capture
   actual pipe bytes and state snapshots before/after; private reads are not
   receiving-caller tools. Keep original failures and setup errors. A source
   success assertion cannot substitute for this recorded completion.
7. Only after native validity and exact protocol profile are established, scope
   the unchanged AmirK-S and mgcrea bridge paths, including permitted raw and
   structured alternatives. Preserve extension/profile/ancestry differences.
   Initial invocation failure and continuation-field loss are different outcomes.
   Unknown remains appropriate when the permitted surface is incomplete.
8. Require human task validity/novelty review and the existing C1 gate. This local
   eligibility work cannot alone qualify the full second domain or authorize
   scaled/held-out confirmation. No applied-only contribution-route change follows.
