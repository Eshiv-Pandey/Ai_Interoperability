# Manuscript V8 evidence and build guide

V8 preserves the registered title, distinct-method objective and full original study scope. Its builder and independent auditor are prepared. **A V8 manuscript must not be created or reported as complete until a real retained V8 allocation and its analysis are available.** No future run ID, bridge success, task effect or native outcome is supplied by this guide.

The inherited evidence remains documented in [the V7 guide](paper-artifact-guide-v7.md). New interpretation inputs are the [method contribution assessment](method-contribution-assessment-v2.md), [independent static code peer](method-contribution-code-peer-v1.json), and [AgentOps semantic peer](agentops-v4-semantic-peer-review-v1.md). These inputs preserve unresolved novelty, method-meter cost asymmetry, the d03 remediation-decision prerequisite gap and both historical h19/h24 failures.

The [V8 builder](../../paper/build_draft_v8.py) requires both `--native-analysis` and `--native-base`. It verifies the real completed GitHub run receipt, matching retained run identity, source input hashes, all 104 allocation/execution/evaluation identities, 65 native payment-tool cells, 39 repeated bridge initiation slots and 13 original authored cases. It reconstructs every arm/status total and all 65 same-case ASGI/TCP pairs. Missing, refused, failed, unclosed and unresolved observations remain in their denominators.

The bridge slots represent three legal original bridge routes repeating the initiation prefix. They are not 39 independent tasks or executed later fault/OTP continuations. The TCP intervention serves exact observed original Apps with owned Uvicorn loopback sockets. It does not qualify the original native server launcher, full ADK shopper, provider quality, financial settlement or whole-route support.

Once the real analysis and retained base exist, run the commands below with their actual paths. Angle-bracket arguments are documentation placeholders, not retained evidence.

```powershell
python paper/build_draft_v8.py --native-analysis <actual-analysis-json> --native-base <actual-retained-base> --output paper/working-draft-v8.md --provenance paper/working-draft-v8.provenance.json
python paper/audit_draft_v8.py --draft paper/working-draft-v8.md --provenance paper/working-draft-v8.provenance.json --native-analysis <actual-analysis-json> --native-base <actual-retained-base> --output paper/working-draft-v8.audit.json
```

The [independent auditor](../../paper/audit_draft_v8.py) reads the published local draft, build provenance and actual evaluated cells without importing the builder or any actor/evaluator. It reconstructs all 65 same-case pairs from both original evaluations and checks every numerical/status table, scope statements, unresolved-pair accounting, source fingerprints and local links. TCP execution wording applies only to capture-verified cells. A passing audit verifies those claims at their disclosed scope; it is not independent human scientific review or publication approval.

All outputs require fresh V8 paths. V7 and historical captures remain untouched. The builder writes no draft if evidence validation fails. A workflow exit, source hash, mechanically complete recipe or purchase observed before a suffix error must not be silently upgraded to full original task or human-gold success.
